# Ingria Hub - Цифровая сущность с памятью и блокчейн-защитой

Ingria - это цифровая сущность, которая взаимодействует через живые аудио-видео сессии с использованием Google Gemini Live API. Система записывает диалоги, сохраняет воспоминания в PostgreSQL с блокчейн-защитой и предоставляет веб-интерфейсы для управления.

## 🚀 Основные возможности

- **Живое аудио-видео взаимодействие** с Google Gemini Live API
- **Система воспоминаний** с автоматическим извлечением и сохранением
- **Блокчейн-защита** воспоминаний для обеспечения неизменности
- **Веб-интерфейсы** для просмотра воспоминаний и блокчейна
- **Telegram бот** для взаимодействия
- **Плавное аудио** с буферизацией и улучшенным качеством

## 🔧 API Endpoints

### Основные
- `POST /ask_ingria` - Задать вопрос Ингрии
- `GET /memories` - Получить воспоминания
- `GET /memories/stats` - Статистика воспоминаний

### Блокчейн
- `GET /blockchain/info` - Информация о блокчейне
- `GET /blockchain/verify` - Проверка целостности
- `POST /blockchain/repair` - Восстановление цепочки
- `GET /blockchain/initialize` - Инициализация блокчейна

## 📊 База данных

Система использует PostgreSQL с таблицами:
- `memories` - Воспоминания с блокчейн-хешами
- `ingria_requests` - Запросы к Ингрии
- `users` - Пользователи
- `files` - Файлы
- `ingria_errors` - Ошибки

## 🔐 Блокчейн-защита

Каждое воспоминание защищено:
- **Хеш SHA-256** содержимого блока
- **Previous hash** для связи с предыдущим блоком
- **Автоматическая проверка** целостности
- **Восстановление** поврежденной цепочки
